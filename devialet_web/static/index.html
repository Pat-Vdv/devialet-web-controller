Choisir la sortie audio Réglages Bluetooth
Appairer un nouvel appareil (PC, téléphone…)
  1. Libérez l'enceinte : coupez le Bluetooth de l'appareil connecté.
  2. Sur le PC : Réglages Bluetooth → Ajouter un appareil → Bluetooth, et laissez la recherche ouverte.
  4. Dans la fenêtre Windows, choisissez « My Phantom System », et non les entrées « PHANTOM ».
  5. Sortie audio → choisissez « My Phantom System ».

En Bureau à distance : réglez le client RDP sur « Lire sur l'ordinateur distant », sinon la sortie n'apparaît pas.

Pour déplacer un bloc, glisser son en-tête (sur écran tactile : appui maintenu puis glisser). Au clavier : boutons Monter et Descendre, ou flèches haut et bas sur ces boutons. L'ordre est enregistré dans ce navigateur.
